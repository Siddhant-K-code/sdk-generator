# OpenFGA JavaScript / TypeScript SDK Context

> Factory worker context for `openfga/js-sdk` (conventions adapted from `openfga/go-sdk/pull/288` `AGENTS.md`/`.claude/rules/*` and verified against `js-sdk`).

## Stack & Verification

- **Package:** `@openfga/sdk` (TypeScript 6 / `@typescript/native`, Node `>=20.19.0`).
- **Key deps:** `axios`, `jose` (private_key_jwt assertions), `tiny-async-pool`, `@opentelemetry/api`, `eslint` 10, `nock`.
- **Verified command:** `make check` (runs `lint` (`eslint .`), `audit` (`npm audit`), and `test` (`npm test`)).
  - If dependencies are missing: `make install` (`npm ci`).
  - Also verify package build when touching types/exports: `make build` (`tsc --outDir dist/`).
  - Auto-fix lint formatting: `make lint-fix` (`eslint . --fix`).
- **Test runner quirk:** Tests use **Node's native `node --test` runner** (`tests/run-tests.mjs` after `pretest` compiles with `tests/tsconfig.spec.json`) plus `tests/helpers/expect.ts` and `nock`, not Jest.

## Repository Layout: Generated vs. Hand-Written

**Critical trap:** 14 `.ts` files carry a stale `NOTE: This file was auto generated by OpenAPI Generator ... DO NOT EDIT.` header, including `credentials/*`, `telemetry/*`, `streaming.ts`, and `tests/streaming.test.ts`. Treat **`.openapi-generator/FILES` (15 entries)** as the source of truth, not file headers.

- **Actually generated (do not hand-edit; route to `config/clients/js/template/`):**
  - `api.ts` (low-level `OpenFgaApi`)
  - `apiModel.ts` (API data models & enums)
  - `constants/index.ts` (shared SDK constants)
  - `index.ts` (top-level barrel exports, **generated**; `config/clients/js/template/index.mustache`)
  - Repo metadata: `.npmrc`, `VERSION.txt`, `CONTRIBUTING.md`, `LICENSE`, etc. (Note: `README.md` is **not** in `.openapi-generator/FILES`.)
- **Ignored in `.openapi-generator-ignore` (hand-maintained):** `.npmignore`, `configuration.ts`, `common.ts`, `base.ts`.

## Shaping a Hand-Written Change

### Worked Pointer: Add a Client-Credentials Option

1. **Types (`credentials/types.ts`):** Add the optional camelCase property to `BaseClientCredentialsConfig` (applies to both `ClientSecretConfig` and `PrivateKeyJWTConfig`), or to one variant if specific to that auth flow. `ClientCredentialsConfig` flows automatically into `Configuration` (`configuration.ts`).
2. **Validation (`credentials/credentials.ts`):** Validate or normalize the new field inside `Credentials.isValid()` under `case CredentialsMethod.ClientCredentials:` (throw `FgaValidationError` on invalid values). Note: JS currently requires `apiAudience` in `isValid()`, unlike other SDKs; do not accidentally relax or break existing validation unless that is the task.
3. **Token request wiring (`credentials/credentials.ts`):**
   - Update `buildClientAuthenticationPayload()` in **both** the `PrivateKeyJWTConfig` and `ClientSecretConfig` branches (and extend `ClientSecretRequest` / `ClientAssertionRequest` interfaces if typed). Keep `...config.customClaims` spread *before* core fields (`client_id`, `client_secret`, `grant_type`, `audience`) so core OAuth params cannot be overwritten.
   - If the option affects token-exchange HTTP behavior, wire it in `refreshAccessToken()` while preserving in-flight promise deduplication (`refreshAccessTokenPromise`) and expiry threshold + jitter (`SdkConstants.TokenExpiryThresholdBufferInSec` + `TokenExpiryJitterInSec`).
4. **Exports check (`index.ts`):** `index.ts` is generated and only exports `{ Credentials, CredentialsMethod }` from `./credentials`. If a new public type must be exported from the package root, route the `index.ts` update to `config/clients/js/template/index.mustache` instead of hand-editing `index.ts`.
5. **Security & telemetry:** Never include secrets/tokens in `FgaApiAuthenticationError` or logs; preserve `TelemetryCounters.credentialsRequest` recording in `refreshAccessToken()`.
6. **Tests (`tests/credentials.test.ts`):** Add cases using `node:test`, `tests/helpers/expect.ts`, and `nock` for both client-secret and private-key-JWT flows where applicable. Do not rely on live network or real timers.

## Idioms & Guardrails

- **Naming:** `camelCase` fields/methods/options, `PascalCase` classes/interfaces/types/enums, `Client*` prefix for wrapper types in `client.ts`, `CredentialsMethod` string enum.
- **Formatting & lint:** ESLint flat config (`eslint.config.js`; ignore legacy `.eslintrc.js`): 2-space indent, double quotes, semicolons, Unix LF. Avoid new `any` and unused vars (`warn`).
- **Config & deprecations:** Prefer `apiUrl` over deprecated `apiScheme` + `apiHost`.
- **Retry & errors:** Retry only HTTP 429 and 5xx (excluding 501); never retry other 4xx; respect `Retry-After` capped at 1800s. Throw typed `FgaError` subclasses from `errors.ts`.
- **Telemetry:** All metrics use `fga_client_*`, no PII, high-cardinality attributes disabled by default.

## PR Rules

- **PR title:** Conventional Commits (`feat`, `fix`, `docs`, `test`, `refactor`, `ci`, `perf`, `chore`, `revert`, `release`, optional scope). Do **not** add a title prefix; factory PRs carry the `factory` label.
- **Do not edit:** `CHANGELOG.md`, `.release-please-manifest.json`, `release-please-config.json`, `package.json` `version`, or generated files in `.openapi-generator/FILES`.
- **Generated changes:** Route to `sdk-generator` (`config/clients/js/template/`), never hand-patch in `js-sdk`.
